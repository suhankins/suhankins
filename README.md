* **[Kerotan and GA-KO Checker Δ](https://github.com/suhankins/delta-kerotan-and-gako-checker)** - Website that reads your save file in [Metal Gear Solid Δ: Snake Eater](https://store.steampowered.com/app/2417610/METAL_GEAR_SOLID_D_SNAKE_EATER/) and tells you which collectables are you missing and where.
